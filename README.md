# StudyBuddy

StudyBuddy is an AI-powered study companion designed to make learning more interactive and productive. Built with ASP.NET MVC and SQL Server, it combines AI-assisted learning with productivity tools, allowing students to generate study materials, chat with AI, manage study sessions, and track their learning progress—all in one platform.

### **Live Demo:** https://studybuddyy.somee.com/

---

## Features

### Authentication
- Secure Login & Sign Up
- User Authentication
- User Profile Management

### AI Study Hub
- Generate AI study notes from any topic
- Upload study materials (`.pdf`, `.docx`, `.txt`, `.md`)
- AI-powered content generation
- AI Chat Assistant

### Learning Tools
- AI Flashcards
- AI Quiz Generation
- Lecture Notes Generator
- Interactive AI Chat
- Learn from uploaded documents

### Productivity
- Pomodoro Focus Timer
- Study Planner
- Study Streak Tracking

### Analytics
- Quiz Performance Tracking
- Progress Graphs
- Learning History

### User Experience
- Responsive Design
- Modern Dashboard
- Clean and User-Friendly Interface

## Installation

1. Clone the repository.

```bash
git clone https://github.com/ishanabeel02/StudyBuddy.git
```

2. Open the project in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server connection string.
5. Add your AI API key.
6. Build and run the project.
